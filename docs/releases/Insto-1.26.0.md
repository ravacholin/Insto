# Insto 1.26.0 · Centro de salud

- **Configuración → Centro de salud** muestra funciones comprobadas, limitaciones e incidentes. Permite comprobar una función, revisar el conjunto, intentar recuperaciones seguras y guardar un informe técnico sanitizado.
- Los permisos y las claves configuradas son evidencia de preparación. Las ejecuciones verificadas y las pruebas funcionales aportan evidencia con vencimiento.
- La conexión local de Omniremote, la autorización de Insto y el estado de cada destino se consultan por separado. La lectura del estado del dispositivo requiere autorización desde el Centro de salud.
- El buzón firmado admite «ver salud operativa». El catálogo vivo incorpora información operativa opcional para las funciones habilitadas.
- El asistente entiende «¿Está funcionando todo?», «¿Por qué no funciona Omniremote?», «¿Está conectado Instinct?», «¿Está funcionando Gemini?», «Comprobá el micrófono», «Hacé un diagnóstico completo», «¿Qué capacidades no están disponibles?», «Intentá solucionar los problemas» y «¿Por qué falló la última orden?». El reconocimiento de esos pedidos puede usar Vosk si el modelo en español está instalado. Las respuestas habladas usan una voz local de Android cuando está disponible.
